# User Manual & Support Plan

# Inventory Management System (IMS)

**Version:** 1.0 (MVP)

**Prepared By:** NasFon

---

# 1. Purpose

This document outlines the user-facing documentation, training approach, and post-launch support plan for the Inventory Management System (IMS).

It is the final document of the planning package and prepares the business for daily operation of the system.

---

# 2. Audience

* Super Admin (business owner)
* Shop Admin / Manager
* Cashier

---

# 3. User Documentation

Planned Materials

* Quick Start Guide — how to log in and navigate the system.
* Role Guides — one guide per role covering the pages and actions they can perform.
* Reference Guides — per module (Products, Customers, Sales, Credit Book, Expenses, Reports, Audit Logs, Settings).
* FAQ — common questions and troubleshooting.
* Receipt/PDF guide — how to print and download receipts, recommended printer sizes.

---

# 4. Training Plan

## 4.1 Training Sessions

Session 1 — Admins

Duration: Half day

Content

* Login, roles, and shops overview.
* Shop and user management.
* Product and customer setup.
* Sales, correction, and reversal.
* Credit book.
* Expenses.
* Reports and dashboard.
* Audit logs and settings.

Session 2 — Cashiers

Duration: 1-2 hours

Content

* Login.
* Creating a sale (multi-product, payment methods).
* Printing and downloading receipts.
* Viewing products and customers.

Session 3 — Super Admin

Duration: Half day

Content

* Multi-shop management.
* Global reporting.
* Audit log review.
* Business settings.
* User management and activation/deactivation.

## 4.2 Training Materials

* Step-by-step written guides.
* Short demo walkthroughs of each module.
* Practice environment (staging) for hands-on training.
* Printed receipt format samples.

## 4.3 Go-Live Support

* Support available during the first weeks after launch.
* A designated support contact for each shop.

# 5. Support Plan

## 5.1 Support Channels

* WhatsApp / phone support (primary for day-to-day issues).
* Email support (for detailed issues and records).
* In-person/remote session for complex issues.

## 5.2 Issue Categorization

| Priority | Definition                                | Response Target |
| -------- | ----------------------------------------- | --------------- |
| Critical | System down, cannot sell, data corruption | Within hours    |
| High     | Feature broken, no workaround             | Same day        |
| Medium   | Incorrect behavior, workaround exists     | 1-2 days        |
| Low      | Minor or cosmetic                         | Next release    |

## 5.3 Common Issues & Solutions

* Forgotten password → Use password reset or admin reset.
* Receipt not printing → Check printer settings and receipt size (80mm thermal / A4 printable).
* Low stock warning → Restock or adjust via product management.
* Incorrect sale → Shop Admin corrects or reverses with a reason.
* Session expired → Log in again.

## 5.4 Escalation

* Cashier issues → Shop Admin.
* Shop Admin issues → Super Admin / business owner.
* System/technical issues → Development contact.
